# Service Store Architecture v1.0.0 - Review Candidate

Architecture and Docker infrastructure candidate for the first real Laravel project of the JP Engineering Framework.

## Product

A professional-services store where Jhon Harold Pizarro can publish, sell, collect requirements for, and manage software-development services.

## Mandatory technology baseline

- PHP 8.2
- Laravel 11
- Bagisto 2.x
- Vue 3
- Inertia.js
- Vite
- Tailwind CSS
- Pinia
- MySQL
- Docker for every runtime and service
