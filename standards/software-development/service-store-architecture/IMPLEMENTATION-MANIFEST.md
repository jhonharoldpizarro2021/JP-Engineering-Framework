## Integration flow

1. Review the package locally.
2. Complete `DECISIONS-TO-APPROVE.md`.
3. Request corrections or approve the complete package.
4. Copy the package contents into the Framework destination.
5. Validate with `git status`, `git diff`, and `git diff --check`.
6. Integrate the ZIP in one commit.
7. Push and save evidence.
8. Open Sprint 6.
9. Create the independent application repository.
10. Generate the executable Docker and Bagisto starter kit using the approved decisions.

## Important separation

This package belongs in the JP Engineering Framework.

The actual Laravel/Bagisto application must be created in a separate repository after approval.
