# Implementation Manifest

## Ruta oficial

`standards/software-development/editorconfig-standard/`

## Archivo operativo

`.editorconfig`

## Archivo legado

`10 Documentación/EditorConfig-Standard.md`

Debe reemplazarse por la redirección incluida para evitar dos fuentes de verdad.

## Integración

1. Copiar `editorconfig-standard` dentro de `standards/software-development/`.
2. Copiar `.editorconfig` a la raíz.
3. Reemplazar el documento legado por la redirección.
4. Ejecutar `git diff --check`.
5. Revisar el diff.
6. Crear y publicar el commit del estándar.
