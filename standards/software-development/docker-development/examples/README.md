# Ejemplos tecnológicos

Los archivos de esta carpeta ilustran cómo declarar extensiones y conexión a servicios existentes.

Antes de utilizarlos se debe revisar:

- nombre real del servicio en Docker Compose;
- ruta real del proyecto dentro del contenedor;
- ubicación de `docker-compose.yml`;
- extensiones específicas del equipo;
- usuario remoto del contenedor;
- puertos y dependencias.

Estos ejemplos no sustituyen la validación técnica de cada proyecto.
