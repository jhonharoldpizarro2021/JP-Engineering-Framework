# Ejemplos tecnológicos

Estos archivos ilustran la conexión de Visual Studio Code con la combinación:

- `compose.yml`
- `compose.dev.yml`

Antes de utilizarlos se debe revisar:

- nombre real del servicio;
- ruta del proyecto dentro del contenedor;
- ubicación de los archivos Compose;
- extensiones requeridas;
- usuario remoto;
- puertos y dependencias;
- comandos de instalación y pruebas.

Los ejemplos no sustituyen la validación técnica del proyecto.
