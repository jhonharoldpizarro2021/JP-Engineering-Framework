## Descripción

Este directorio contiene el paquete documental oficial del **Git Workflow Standard** del JP Engineering Framework.

El estándar define un modelo gobernado y trazable para administrar ramas, cambios, integraciones, revisiones, despliegues, excepciones e incidentes en repositorios basados en Git.
