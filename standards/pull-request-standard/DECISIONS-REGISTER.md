# Decisions Register

1. Todo cambio a ramas protegidas utiliza Pull Request.
2. El título cumple Commit Convention Standard.
3. Un Pull Request representa un único propósito.
4. La descripción, pruebas y evidencia son obligatorias.
5. Draft PR no puede integrarse.
6. CI en verde es requisito.
7. Una aprobación para cambios normales.
8. Dos aprobaciones para cambios de alto riesgo.
9. El autor no se autoaprueba.
10. Cambios materiales requieren nueva revisión.
11. Squash merge es la estrategia predeterminada.
12. Las excepciones de emergencia conservan trazabilidad.
