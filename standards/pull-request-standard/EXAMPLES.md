# Examples

## Títulos válidos

- `feat(auth): add password reset flow`
- `fix(payments): prevent duplicate charge`
- `docs(docker): document production startup`
- `security(api): reject expired access tokens`

## Títulos inválidos

- `Update files`
- `feature: login`
- `fix(general): changes.`
- `WIP`
- `feat(auth): Add password reset flow`

## Pull Request correcto

- Un objetivo.
- Issue real.
- Pruebas descritas.
- Evidencia adjunta.
- Riesgos identificados.
- CI en verde.
- Aprobaciones completas.

## Pull Request incorrecto

- Mezcla funcionalidad, refactor y formato.
- No explica el cambio.
- Carece de pruebas.
- Incluye secretos.
- Solicita integrar con checks fallidos.
