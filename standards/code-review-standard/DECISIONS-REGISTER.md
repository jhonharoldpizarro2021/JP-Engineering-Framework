# Decisions Register

1. Revisión independiente obligatoria.
2. Autor y revisor tienen responsabilidades explícitas.
3. Seguridad, funcionalidad, mantenibilidad, pruebas y operación son áreas mínimas.
4. Comentarios clasificados por severidad.
5. Bloqueos no pueden aprobarse para corregirse después.
6. Cambios materiales requieren nueva revisión.
7. Una aprobación normal y dos para alto riesgo.
8. Decisiones críticas quedan documentadas en el Pull Request.
9. Código de IA recibe el mismo rigor.
10. Preferencias personales no sustituyen estándares.
