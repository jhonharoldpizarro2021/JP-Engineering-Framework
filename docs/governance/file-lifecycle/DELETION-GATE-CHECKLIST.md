# Deletion Gate Checklist

An artifact cannot be marked SAFE TO DELETE until every applicable control passes.

- [ ] Newer official or equivalent version exists.
- [ ] Authorized backup exists.
- [ ] Backup opens successfully.
- [ ] Backup can be downloaded or recovered.
- [ ] SHA-256 or equivalent integrity identifier matches.
- [ ] Manifest or registry identifies the artifact.
- [ ] Artifact is not the only copy.
- [ ] Artifact is not required by an active chat or workflow.
- [ ] Sensitive information is protected.
- [ ] Chat 1 recommends deletion.
- [ ] Chat 0 approves deletion.
- [ ] Manual deletion will be recorded.
