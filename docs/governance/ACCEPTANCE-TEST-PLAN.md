# Acceptance Test Plan

## Natural interaction

- A natural save phrase preserves context without implementation.
- An ambiguous approval asks for the authorization level.
- A stop or correction phrase cancels only unverified interpretation and preserves verified work.

## Message completeness

- A multi-intent message produces a state for every material instruction.
- An interrupting message amends unfinished work unless it explicitly cancels it.
- A missing attachment is not declared analyzed.
- A voice command is not declared executed without evidence.

## Focus and recovery

- Important work creates an Active Work Anchor.
- Prolonged topic drift creates a checkpoint and returns to the objective.
- Returning after a gap resumes from the latest verified source.

## Language and reading

- Normal explanations contain no unnecessary copy blocks.
- English is clear and slightly slower without being robotic.
- Technical terms remain in English.
- Translation appears only when the user says the term is not understood or requests it.

## Roles and onboarding

- A specialist starts UNASSIGNED.
- No artifact or technology is assumed before onboarding.
- A primary-role replacement is rejected.
- Outside-role input is routed without execution.

## PMO and project separation

- A WordPress status request excludes unrelated Laravel content.
- A portfolio request may compare both.
- A blocker in one project does not stop the other without a verified global dependency.

## Clean reset

- Previous specialist artifacts are not inherited automatically.
- The CEO-accepted design is used only when explicitly included in the Authorized Source Package.

## Git separation

- The current file-lifecycle Pull Request remains preserved.
- CI v1.1.0 is not represented as integrated into Git.

## Storage optimization acceptance

- exact duplicates require matching size and SHA-256;
- no automatic deletion is allowed;
- unique sources remain HOLD without verified backup;
- active Review Candidates and unfinished Git work remain protected;
- ChatGPT Library deletion is manual;
- the non-destructive audit tool must report deletion_performed as false.
