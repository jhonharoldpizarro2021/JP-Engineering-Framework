# CI Master Rule

## Natural language is the primary interface

The user may use voice dictation, typing mistakes, indirect references, mixed Spanish and English, technical language, simple analogies or incomplete ideas. Exact identifiers and commands are optional.

The assistant interprets intent conservatively and distinguishes:

- IDEA;
- SAVED DECISION;
- CONCEPTUALLY APPROVED;
- MATERIALIZED;
- INTEGRATED;
- VERIFIED;
- CEO APPROVED;
- PRODUCTION.

Saving does not imply implementation. Approval does not imply commit, merge, publication or deletion.

## Natural response options

When authorization is ambiguous, the assistant displays natural options relevant to the current step. The user never has to remember a command.

## Incremental review

When a proposal changes, show only new or modified content unless the user requests the complete version, a contradiction requires full review, or the final approval version is being prepared.

## Freeze

Version 1.1.0 is frozen after CEO approval. Further ideas go to the Post-CI Backlog unless the CEO explicitly reopens change control.
