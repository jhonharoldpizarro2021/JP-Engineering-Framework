# Command and Natural Expression Catalog

## Save and preserve

Examples: guarda esto; guárdalo; recuérdalo; regístralo; no olvides esto; agrégalo a lo pendiente; déjalo anotado; esto es importante; esto forma parte de la historia; indexalo.

Default meaning: classify and preserve the information without physical implementation.

## Defer

Examples: guárdalo para después; esto va después del MVP; déjalo pendiente; no hagas nada todavía; retomamos esto después; esto es lo primero cuando terminemos.

Default meaning: create a deferred decision with trigger, priority, owner, dependencies and recovery context.

## Approve

Examples: aprobado; sí, esa es la idea; aprobado para probar; aprobado para materializar; aprobado para integrar; aprobado para merge; aprobado para producción.

When the authorization level is ambiguous, ask which level applies.

## Implement

Examples: implementa esto; implementa eso que hablamos; aplica esta regla; incorpora este cambio; implementa todo lo aprobado; realiza implementación completa.

Full implementation requires real deliverables, evidence, status separation, tests, risks and honest reporting of anything that remains manual or blocked.

## Materialize and export

Examples: materialízalo; crea el documento; genera el archivo; genera el ZIP; genera el PDF; prepara un Review Candidate; muéstrame el contenido primero; genera solo el respaldo; exporta el conocimiento; genera el Informe para Chat Cerebro.

## Transfer between chats

Examples: pásalo al Chat 0; prepara esto para Chat 1; genera el handoff; dime en qué chat sigo; dame el texto para pegar.

A copy-ready block appears only when exact copying is necessary.

## Stop and correct

Examples: no hagas nada; detente; cancela; no guardes eso; no lo implementes; déjalo como estaba; no era eso; no me entendiste; descarta esa propuesta.

These expressions override earlier execution language. The assistant stops, preserves verified work, reformulates and waits for confirmation.

## Master Task

Examples: recuérdame; prográmalo; avísame cuando ocurra; agrégalo a la Tarea Maestra; no crees otra tarea.

Default behavior: update the single Master Task when technically safe and authorized.
