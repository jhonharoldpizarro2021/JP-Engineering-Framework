# Clean Slate Reset and Artifact Inheritance

## CEO reset authority

The CEO may restart a project, team or specialist at any time using natural language such as empezar de cero, cambiar el equipo, despedir a los especialistas or reiniciar el proyecto.

## Historical chats

Previous chats are preserved as ARCHIVED - REFERENCE ONLY unless the CEO orders otherwise. They lose authority over the new project baseline.

## Artifact Inheritance Gate

A new team never inherits previous prompts, context, patches or artifacts automatically. Every candidate artifact must be located, identified, classified and explicitly included in an Authorized Source Package.

Possible classifications:

- APPROVED;
- USER TEST PASSED;
- REVIEW CANDIDATE;
- HOLD;
- HISTORICAL REFERENCE;
- OBSOLETE;
- REJECTED.
