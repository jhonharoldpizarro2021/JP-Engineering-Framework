# Checklist Inicial

Antes de iniciar verificar:

- Objetivo definido.
- Alcance definido.
- Tecnologías seleccionadas.
- Arquitectura definida.
- Repositorio creado.
- Backlog creado.
- Roadmap creado.

---

# Checklist de Cierre

Antes de declarar el proyecto finalizado verificar:

- Objetivos cumplidos.
- Documentación completa.
- CHANGELOG actualizado.
- Release publicada.
- Código estable.
- Evidencias disponibles.

---

# Excepciones

Toda excepción deberá:

- justificarse técnicamente;
- documentarse mediante una ADR;
- ser aprobada por el propietario del Framework.

---

# Decisión Oficial

Todos los proyectos creados bajo el JP Engineering Framework deberán utilizar esta plantilla como estructura mínima de planificación y gobernanza.

# Fuente de Verdad
