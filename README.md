## Purpose

This package is the approved local baseline for natural interaction, command interpretation, portfolio governance, project separation, architectural analysis, context recovery, enterprise specialist onboarding, the clean WordPress pilot, and safe storage optimization without automatic deletion.

The user does not need to memorize exact commands. Natural language is the primary interface. Chat 0 operates as Portfolio Director and PMO while the user remains CEO.

## Immediate operating decisions

- No further additions are incorporated into v1.1.0 unless the CEO explicitly reopens change control.
- The failed post-MVP specialist cycle is closed.
- Previous specialist chats and their artifacts are not used in the new pilot.
- Only the Framework already integrated in Git remains authoritative.
- The CEO-accepted visual design remains preserved as an available candidate, but no specialist may use it unless Chat 0 explicitly includes it in an Authorized Source Package.
- New governance changes remain in this local backup until the WordPress MVP is completed, tested and approved.
- The existing file-lifecycle Pull Request remains preserved and unfinished; it is not replaced by this package.
- Storage optimization is non-destructive by default. Chat 0 may inventory, classify and recommend, but deletion is manual and requires the Safe Deletion Gate plus explicit CEO approval.
- Exact duplicates are determined by size and SHA-256, not by filename alone.
