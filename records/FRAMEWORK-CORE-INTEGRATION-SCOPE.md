# Framework Core Integration Scope

Source baseline: v1.2.0 Approved Local Baseline

This payload contains only the generic JP Engineering Framework core required for:
- portfolio and PMO governance;
- specialist lifecycle and onboarding;
- context and interruption management;
- local-first integration controls;
- storage optimization and Safe Deletion Gate;
- reusable templates;
- non-destructive storage audit tooling;
- minimal traceability records.

Explicitly excluded:
- WordPress pilot files and WordPress-specific governance;
- stale Git recovery checkpoint;
- personal manuals;
- historical backup packages;
- daily evidence;
- failed or superseded scripts;
- meeting-only records;
- project-specific source code.

This payload must be integrated into a clean branch created from origin/main.
