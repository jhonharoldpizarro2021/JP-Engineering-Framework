# Contributing

## Principios

Las contribuciones deben preservar:

- coherencia documental;
- trazabilidad;
- compatibilidad entre estándares;
- revisión formal;
- control de versiones;
- separación clara de responsabilidades.

## Flujo recomendado

1. Crear una rama de trabajo.
2. Elaborar o modificar el estándar.
3. Actualizar metadatos e historial.
4. Ejecutar revisión técnica.
5. Crear Pull Request.
6. Resolver observaciones.
7. Obtener aprobación formal.
8. Publicar la nueva versión.

## Requisitos mínimos para un Pull Request

- objetivo claro;
- alcance definido;
- evidencia de revisión;
- impacto documentado;
- versión actualizada cuando corresponda;
- referencias relacionadas;
- ausencia de secretos o información sensible.
