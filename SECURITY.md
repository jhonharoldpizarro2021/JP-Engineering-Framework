# Security Policy

## Reporte de vulnerabilidades

No publiques vulnerabilidades, credenciales, tokens o información sensible en Issues, Pull Requests o discusiones públicas.

## Alcance

Esta política cubre:

- contenido del repositorio;
- automatizaciones;
- pipelines;
- configuraciones;
- dependencias;
- documentación con implicaciones de seguridad.

## Reglas mínimas

- No almacenar secretos en Git.
- Aplicar mínimo privilegio.
- Mantener dependencias actualizadas.
- Registrar incidentes y acciones correctivas.
- Revocar inmediatamente credenciales expuestas.
